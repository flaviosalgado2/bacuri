Sistema completo implementado com sucesso! 🎉
O que foi construído
Stack nativa do Nuxt 4
- Nuxt UI v4 + Tailwind CSS v4 — interface moderna, responsiva e com tema claro/escuro
- Nuxt Auth Utils — autenticação segura com sessões criptografadas (Scrypt)
- Drizzle ORM + PostgreSQL — banco de dados relacional tipado
- Zod — validação de dados em todas as APIs e formulários
Funcionalidades
- ✅ Cadastro de novos usuários (/register)
- ✅ Login/logout seguro (/login)
- ✅ Sidebar de navegação padrão de sistema
- ✅ Dashboard com resumo financeiro e contas próximas do vencimento
- ✅ Contas a pagar e a receber (listagem separada)
- ✅ CRUD completo de contas:
- Nome, tipo, valor
- Data de vencimento
- Data limite para pagamento com desconto
- Observações
- Status pago/pendente
- ✅ Marcar conta como paga/pendente com um clique
- ✅ Exclusão com confirmação
- ✅ Filtros por tipo, status e período
- ✅ Isolamento total: cada usuário vê apenas suas contas
- ✅ Usuário root vê e gerencia todas as contas de todos os usuários

Como rodar
# Subir o PostgreSQL
docker compose up -d postgres

# Instalar dependências (já feito)
npm install

# Aplicar migrations do banco
npm run db:migrate

# Iniciar em desenvolvimento
npm run dev
Acesse: http://localhost:3000
Rotas principais
- /login — Entrar
- /register — Criar conta
- / — Dashboard
- /contas/pagar — Contas a pagar
- /contas/receber — Contas a receber
- /contas — Todas as contas com filtros
- /contas/pagar/nova e /contas/receber/nova — Nova conta
- /contas/:id/editar — Editar conta
